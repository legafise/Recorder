# PomanRecorder

Рекордер звука для Windows в стиле студийного пульта: запись с выбранного микрофона, библиотека записей с поиском,
волна и спектроанализатор, рэк эффектов с ручками, тёмная и светлая темы.

## Установить
Скачайте [`Установщик/PomanRecorder-Setup-1.0.exe`](Установщик/PomanRecorder-Setup-1.0.exe) и запустите.
Права администратора не нужны. Если Windows покажет «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»:
установщик просто не подписан платной цифровой подписью.

Записи сохраняются в «Документы\PomanRecorder».

## Возможности
- запись с любого микрофона, моно или стерео, пауза, проверка уровня входа;
- индикатор уровня L/R, спектроанализатор, живая волна во время записи;
- библиотека: поиск, сортировка, мини-волны, переход к файлу в Проводнике, копирование файла в буфер обмена;
- эффекты: обрезка тишины, срез низов и верхов, шумоподавление, усиление, фейды, нормализация, с предпрослушиванием;
- горячие клавиши, тёмная и светлая темы (по умолчанию как в Windows).

Подробное руководство: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Из исходников
- `recorder.py` — окно (pywebview) и связь интерфейса со звуком
- `audio_core.py` — запись, воспроизведение, эффекты, анализ (sounddevice, numpy, scipy)
- `ui/` — интерфейс на HTML, CSS и JavaScript
- `Запуск.bat` — запуск из исходников (нужен Python 3.10+)
- `build/build.bat` — сборка `PomanRecorder.exe` (PyInstaller) и установщика (Inno Setup: `winget install JRSoftware.InnoSetup`)
