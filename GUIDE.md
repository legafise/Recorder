# PomanRecorder Audio Studio — инструкция

## Запуск
Дважды щёлкните ярлык **«PomanRecorder»** на рабочем столе (или `PomanRecorder.exe` в этой папке).
Больше ничего ставить не нужно: Python и все библиотеки упакованы внутрь exe. Окно открывается за 2–3 секунды.

- Если программа уже открыта, повторный запуск просто покажет её окно, вторая копия не откроется.
- Настройки (`settings.json`) и папка `Recordings` хранятся **рядом с exe**. Если перенесёте exe в другое место, переносите вместе с ними
  (или выберите старую папку с записями кнопкой «Сменить» в библиотеке).
- Ярлык можно закрепить на панели задач или в «Пуске»: ПКМ по ярлыку → «Закрепить…».

## Как поделиться с другом
Отправьте ему файл **`installer\PomanRecorder-Setup-1.0.exe`** (≈37 МБ).
- Установка: «Далее» → «Далее» → готово. Права администратора не нужны, программа ставится для текущего пользователя.
- После установки появятся ярлыки на рабочем столе (если оставить галочку) и в меню «Пуск».
- У установленной программы записи сохраняются в **«Документы\PomanRecorder»**, а настройки в `%APPDATA%\PomanRecorder`.
- Удаляется как обычная программа: «Параметры → Приложения → PomanRecorder → Удалить». Записи при этом остаются.
- Установщик не подписан цифровой подписью (она платная), поэтому Windows при первом запуске может показать
  «Windows защитила ваш компьютер». Нужно нажать «Подробнее» → «Выполнить в любом случае».
- Python ставить не нужно: он уже внутри программы.
- Окно программы рисуется компонентом Microsoft Edge WebView2. В Windows 11 он есть всегда, а на Windows 10 бывает не везде.
  Если его нет, установщик сам скачает его с сайта Microsoft и установит (нужен интернет, около минуты).

## Как устроено окно
```
┌──────────────┬──────────────────────────────────────────┐
│  БИБЛИОТЕКА  │  ДЕКА: название, таймкод, волна,         │
│  поиск,      │  кнопки воспроизведения и действий       │
│  сортировка, │                                          │
│  записи      │                                          │
├──────────────┴──────────────────────────────────────────┤
│  КОНСОЛЬ ЗАПИСИ: микрофон · REC · индикатор уровня · спектр │
└─────────────────────────────────────────────────────────┘
```

## Тема оформления
Справа вверху три кнопки: 🖥 **как в системе** (по умолчанию: тёмная или светлая вслед за Windows), ☀ **светлая**, 🌙 **тёмная**.
Выбор запоминается. В светлой теме светлыми становятся и экраны: волна, индикатор уровня, спектр, таймкод.

## Запись
1. **Источник** — щёлкните по названию микрофона и выберите нужный. В конце списка есть «Обновить список устройств», если вы подключили микрофон после запуска.
2. **Моно / Стерео** — для голоса хватит моно. Если микрофон монофонический, запись всё равно будет в моно.
3. **Тест входа** — включает индикатор уровня без записи, чтобы проверить, что микрофон слышит вас.
4. Большая красная кнопка **REC** (или `Ctrl+R`) начинает запись. Кнопка превращается в «стоп», в верхней панели загорается бейдж `REC`, а на деке бежит живая волна.
5. **Пауза / Продолжить** — приостанавливает запись, продолжение идёт в тот же файл.
6. Ещё раз **REC** (или `Ctrl+R`) — запись сохраняется и сразу появляется в библиотеке.

**Индикатор уровня (LEVEL):** голубой — нормально, жёлтый — громко, красный и надпись `CLIP` — перегруз (отодвиньтесь от микрофона или уменьшите его громкость в Windows).
**SPECTRUM** показывает, на каких частотах звучит сигнал: при записи — с микрофона, при воспроизведении — из файла.

Файлы называются `Запись ГГГГ-ММ-ДД ЧЧ-ММ-СС.wav` и лежат в папке `Recordings` рядом с программой.
Путь виден внизу библиотеки, а кнопкой **«Сменить»** можно выбрать другую папку.

## Навигация по записям
- **Поиск** — фильтрует по названию (`Ctrl+L`).
- **Дата / Имя / Длина / Размер** — сортировка; повторный клик меняет направление. При сортировке по дате записи сгруппированы: «Сегодня», «Вчера» и т.д.
- У каждой записи видна длительность и мини-волна.
- Клик выбирает запись, двойной клик сразу её играет. Стрелки `↑`/`↓` переключают записи.
- **Волна:** клик или перетаскивание мышью перематывает, при наведении видно время. `←`/`→` — на 5 секунд, `Home` — в начало.
- **Правый клик** по записи открывает меню со всеми действиями.
- Если добавить или удалить файлы в папке через Проводник, список обновится сам (или нажмите `F5`).

## Как использовать файл записи
- **В папке** (`Ctrl+E`) — открывает Проводник с выделенным файлом.
- **Копировать** (`Ctrl+C`) — кладёт сам файл в буфер обмена: вставьте его через `Ctrl+V` в Telegram, письмо, другую папку и т.д.
- **Копировать путь** (`Ctrl+Shift+C`, есть в меню правого клика) — путь к файлу текстом.
- ✏ **Переименовать** (`F2`), 🗑 **Удалить** (`Delete`). Удалённые записи попадают в **Корзину**, их можно восстановить.

## Рэк эффектов
Выберите запись → **Эффекты** (`Ctrl+F`). Справа выезжает рэк из 7 модулей. Вверху видна цепочка обработки: горящие блоки — включённые эффекты.

- **Переключатель** в модуле включает или выключает эффект.
- **Ручка (knob)** вращается как настоящая: захватите её мышью и ведите по кругу — по часовой стрелке больше, против часовой меньше. Колесо мыши тоже крутит. С `Shift` подстройка точнее, двойной клик возвращает значение по умолчанию. Если покрутить ручку, эффект включится сам.

| Модуль | Зачем | С чего начать |
|---|---|---|
| Обрезка тишины | убирает тишину в начале и конце | −45 дБ |
| Срез низов | гул, вибрации, стук по столу | 80 Гц (для голоса до 120) |
| Срез верхов | шипение, свист | 8 кГц |
| Шумоподавление | ровный фон: вентилятор, улица | 50–70 % |
| Усиление | громче или тише | +6 дБ |
| Фейды | мягкое начало и конец | 300 мс |
| Нормализация | максимально громко без перегруза | −1 дБ |

- 🎧 **Прослушать** — сразу играет результат. Волна на деке становится янтарной, файл при этом не меняется.
- **Сохранить как новую** — создаёт `… (обработано).wav`, оригинал остаётся как был.
- **Перезаписать** — заменяет исходный файл, старая версия уходит в Корзину.
- ⟳ — сбросить все ручки.

Шумоподавление «учится» на самых тихих местах записи, поэтому лучше работает, когда в записи есть секунда-две без голоса.

## Горячие клавиши
Их полный список открывается кнопкой ⌨ справа вверху.

| Клавиша | Действие |
|---|---|
| `Ctrl+R` | начать / остановить запись |
| `Пробел` / `Enter` | проиграть / пауза |
| `←` / `→` | перемотка на 5 с |
| `↑` / `↓` | предыдущая / следующая запись |
| `Ctrl+E` | показать в папке |
| `Ctrl+C` / `Ctrl+Shift+C` | копировать файл / путь |
| `Ctrl+F` | эффекты |
| `F2` / `Delete` | переименовать / удалить в Корзину |
| `Ctrl+L` | поиск |
| `F5` | обновить список |
| `Esc` | закрыть меню, рэк или диалог |

## Если что-то не так
- **Микрофона нет в списке** — подключите его и выберите «Обновить список устройств».
- **Индикатор не двигается при «Тесте входа»** — проверьте, что в «Параметры → Конфиденциальность → Микрофон» разрешён доступ для классических приложений.
- **Окно пустое или программа пишет про WebView2** — не установлен компонент Microsoft Edge WebView2.
  Программа сама предложит открыть страницу загрузки Microsoft: установите его и запустите PomanRecorder снова.
- **Программа сообщает, что не смогла запуститься** — подробности записаны в файл
  `%LOCALAPPDATA%\PomanRecorder\error.log` (вставьте этот путь в адресную строку Проводника). Пришлите его разработчику.
- **Ничего не происходит или файл пропал** — скорее всего, его заблокировал антивирус. Это частая ложная тревога
  на программы, собранные из Python: восстановите файл из карантина и добавьте его в исключения.
- **«Windows защитила ваш компьютер»** — нажмите «Подробнее» → «Выполнить в любом случае».
- Если закрыть окно во время записи, запись автоматически остановится и сохранится.

## Файлы в папке
Для работы нужны только:
- `PomanRecorder.exe` — программа
- `installer\PomanRecorder-Setup-1.0.exe` — установщик, чтобы поделиться программой
- `Recordings\` — ваши записи (WAV, 16 бит)
- `settings.json` — ваши настройки: микрофон, тема, папка, положение ручек (появляется сам)

Остальное — исходный код, он нужен, только если захочется что-то поменять в программе:
- `recorder.py`, `audio_core.py`, `ui/` — код окна, звука и интерфейса
- `run.bat` — запуск прямо из исходников, без пересборки (нужен установленный Python)
- `build\build.bat` — пересобрать `PomanRecorder.exe` и установщик после изменений в коде
  (нужны Python и Inno Setup: `winget install JRSoftware.InnoSetup`)
